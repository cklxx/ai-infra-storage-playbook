# ai-infra-storage-playbook

AI Infra 存储与传输方向的手册仓库。`aisp/` 是全部项目的根，一个子目录一个项目，每个项目自带文档、可执行脚本与校验。`aisp` 同时作为 Python 包名，便于按包安装与引用。

| 目录 | 是什么 | 状态 |
|---|---|---|
| [`aisp/bench/`](aisp/bench/README.md) | playbook 与 bench 评估集：生成、运行与校验 AI Infra 存储传输侧评估集的程序 | 现有 |
| `aisp/tla/` | TLA+ 形式化规格 | 规划中 |

各项目的用法看它自己的 `README.md`。仓库根只放这份索引、`aisp/` 与 `.gitignore`。
